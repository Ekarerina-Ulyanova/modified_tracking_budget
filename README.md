## Overview

modified_tracking_budget is a personal finance tool designed to empower individuals to manage their money effectively. It helps users track income and expenses, categorize spending habits, and gain valuable insights into their financial health for better budgeting and informed decision-making.

## Core features

1. **Budget Management**: Allows users to track income and expenses, providing control over personal finances.
2. **SQLite Database Integration**: Utilizes an SQLite database for persistent storage of financial data, ensuring reliability and data integrity.
3. **Expense Categorization**: Enables users to categorize expenses into different categories for detailed spending analysis.

## Installation

Install modified_tracking_budget using one of the following methods:

**Build from source:**

1. Clone the modified_tracking_budget repository:
```sh
git clone https://github.com/Ekarerina-Ulyanova/modified_tracking_budget
```

2. Navigate to the project directory:
```sh
cd modified_tracking_budget
```

3. Install the project dependencies:

```sh
pip install -r requirements.txt
```
